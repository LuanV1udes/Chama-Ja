Tela de entrada

O QR code muda a cada minuto, então uma foto dele não serve para pegar senha de casa. Ele aparece num tablet na porta do estabelecimento, num endereço secreto próprio.

Link do tablet da entrada

Abra este endereço no tablet que ficará na porta. Ele só mostra o QR code e não dá acesso ao painel, por isso não precisa de login.

Abrir a tela agora

Como montar

  • Tablet externo (porta): abre o link acima, em tela cheia e com a tela sempre ligada.
  • Tablet interno (atendimento): abre o painel e faz login. É onde se chama, pula e finaliza as senhas.
  • Reserva (celular ou computador): pode abrir o painel ao mesmo tempo, com o mesmo login, se o tablet interno falhar. Também serve de reserva para o tablet externo: basta abrir o mesmo link nele.

Gerar um novo link

Use se o link do tablet foi compartilhado sem querer ou se o tablet sumiu. O link antigo deixa de funcionar na hora e é preciso abrir o novo no tablet da entrada.
